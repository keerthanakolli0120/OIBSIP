# Random Password Generator

## Description
This is a Python program that generates strong random passwords based on user preferences.

## Features
- User chooses password length
- Minimum password length of 8 characters
- Supports:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Input validation
- Generate multiple passwords without restarting

## Technologies Used
- Python
- random
- string

## How to Run

1. Open the project folder.
2. Activate the virtual environment.
3. Run:

```bash
python password_generator.py
```
