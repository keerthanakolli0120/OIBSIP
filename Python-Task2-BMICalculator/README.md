# BMI Calculator

## Description
This is a simple BMI (Body Mass Index) Calculator built using Python. It calculates the BMI based on the user's weight and height and classifies the result into a health category.

## Features
- Accepts weight and height as input
- Calculates BMI
- Displays BMI up to 2 decimal places
- Classifies BMI into:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Handles invalid input

## Technologies Used
- Python

## How to Run

1. Open the project folder.
2. Activate the virtual environment.
3. Run:

```bash
python bmi.py
```
