# AI Voice Assistant

## Description
This is a simple AI Voice Assistant built using Python. It listens to the user's voice and performs basic tasks.

## Features
- Voice Recognition
- Text-to-Speech
- Responds to Greetings
- Tells Current Time
- Tells Current Date
- Searches Google
- Opens Google
- Opens YouTube

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3

## How to Run

1. Open the project folder.
2. Activate the virtual environment.
3. Install the required libraries.
4. Run:

```bash
python assistant.py
```
