# Chat Application

## Description
This is a simple real-time chat application built using Python sockets and threading. It allows two users to communicate on the same computer using localhost.

## Features
- Server and client programs
- Real-time messaging
- Two-way communication
- Timestamp for each message
- Graceful client disconnection
- Runs on localhost

## Technologies Used
- Python
- socket
- threading
- datetime

## How to Run

1. Start the server:

```bash
python server.py
```

2. Open another terminal and start the first client:

```bash
python client.py
```

3. Open one more terminal and start the second client:

```bash
python client.py
```

4. Start chatting!
